# 中国家庭资产配置分析器

一个面向中国国内用户的静态网页工具，用于录入家庭资产、选择金融资产目标组合、查看风险收益摘要和再平衡建议。

## 功能

- 人民币资产录入：存款、货币基金、债券/固收、A股宽基指数、红利/低波策略、行业/主题基金、个股、港股/中概、美国核心宽基、美股科技卫星、全球除美权益、黄金、公募 REITs、保险/养老金、房产、其他资产。
- 美股录入分层：标普500、美国全市场、普通美股 QDII 归为“美国核心宽基”；纳指100、AI、科技成长基金归为“美股科技卫星”，避免普通用户把主仓和增强仓混在一起。
- 组合选择：按波动率从低到高展示多个国内化组合，并默认推荐“国内均衡配置”。
- 帮我选择：根据资金期限、可接受下跌、目标偏好自动推荐组合。
- 高收益潜力模型：提供“长期进取增长”和“单身极进取 10%+”。后者使用历史乐观口径，核心配置美国核心宽基和科技成长卫星，适合极高风险承受力用户，不代表收益承诺。
- 资产占比图：分别展示家庭总资产和可投资金融资产结构。
- 一句话诊断：用更直观的语言说明当前组合偏保守、偏激进或接近目标。
- 再平衡建议：只对可投资金融资产给出加减金额；房产、保险/养老金作为观察项。
- 本地历史：使用浏览器 localStorage 保存快照，不上传数据。

## 本地运行

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 模型口径

- 稳健和均衡模型：使用偏保守的长期资本市场假设，强调现金流、固收、黄金和多元权益。
- 进取模型：提高美国核心宽基、A股宽基、科技成长和行业主题比例，同时压低港股/中概至卫星仓。
- 10%+ 极进取模型：使用历史乐观口径，面向长期单身或高风险承受力用户，需能接受深度回撤和多年低迷。

## 风险提示

本工具仅用于教育和个人规划参考，不构成投资、税务、法律或保险建议。页面中的收益率、波动率和相关性是假设参数，不代表任何产品的未来表现。
